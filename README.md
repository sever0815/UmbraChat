# cchat (Anonymous Edition)

> 🛡️ **An encrypted, zero-trace console chat designed for absolute privacy.**

`cchat` — это легковесный консольный чат на C++, созданный по принципу **Zero-Knowledge & Zero-Logs**. Никакая история переписок не сохраняется на диск ни на стороне клиента, ни на сервере. Все сообщения существуют исключительно в оперативной памяти и буфере терминала до закрытия программы.

---

## ✨ Ключевые особенности

* **Zero-Trace Architecture:** Полное отсутствие файлов истории, баз данных и системных логов.
* **RAM-Only сессии:** Сообщения отображаются в терминале и мгновенно уничтожаются при закрытии программы или выходе по `/exit`.
* **Безопасные конфиги в `~/.cchate/`:** Параметры подключения и ключи хранятся в изолированной папке с правами `700` (`rwx------`).
* **Быстрое CLI-меню:** Удобный выбор сохраненных серверов или прямое разовое подключение.
* **Минимализм:** Чистый C++17 без тяжелых сторонних зависимостей.

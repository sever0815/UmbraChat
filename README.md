## 💡 Варианты названия проекта

1. **`cchat-anon`** или **`cchat-ghost`** — просто и понятно, сразу отсылает к оригинальному репозиторию, но подчеркивает приватность.
2. **`UmbraChat`** (от латинского *umbra* — тень) — звучит технологично и стильно для конфиденциального утилитарного софта.
3. **`NullChat`** — подчеркивает концепцию «ноль следов, ноль истории на диске».
4. **Оставить `cchat**` (с уточняющим описанием в README вроде *Anonymized Console Chat*).

# 📄 Шаблон `README.md`

```markdown
# cchat (Anonymous Edition)

> 🛡️ **An encrypted, zero-trace console chat designed for absolute privacy.**

`cchat` — это легковесный консольный чат на C/C++, созданный по принципу **Zero-Knowledge & Zero-Logs**. Никакая история переписок не сохраняется на жесткий диск ни на стороне клиента, ни на сервере. Все сообщения существуют исключительно в оперативной памяти и буфере терминала до завершения сеанса.

---

## ✨ Ключевые особенности

* **Полная анонимность (Zero Logs):** Никаких баз данных, файлов логов или кэша на накопителях. 
* **RAM-Only сессии:** Вся переписка отображается только в буфере терминала. При выходе (`/exit`) память очищается.
* **Изолированный конфиг:** Настройки серверов, ключи и псевдонимы хранятся в защищенной локальной директории `~/.cchate/` с правами доступа `700` / `600`.
* **Минималистичный CLI:** Удобное интерактивное меню для быстрого выбора или добавления серверов.
* **Без лишних зависимостей:** Чистый C++17, высокая скорость работы и низкое потребление ресурсов.

---

## 🗂️ Интерактивное меню

При запуске программы вас встретит консольный интерфейс:

```text
=== cchat (Anonymous Edition) ===
(1) Выбрать Сервер
(2) Подключиться (разово)
(0) Добавить сервер
--------------------------------
Выберите пункт: 

```

* **(1) Выбрать сервер:** Быстрое подключение к одному из предварительно сохраненных в `~/.cchate/` узлов.
* **(2) Подключиться:** Разовое подключение по указанному адресу (`ip:domain`) без сохранения данных в конфиг.
* **(0) Добавить сервер:** Интерактивный мастер для сохранения параметров сервера (имя, адрес, ключ, никнейм) в защищенную папку.

## 🚀 Сборка и установка

Для сборки проекта требуется компилятор с поддержкой **C++17** и утилита **Make**.

1. Клонируйте репозиторий:
```bash
git clone [https://github.com/sever0815/cchat.git](https://github.com/sever0815/cchat.git)
cd cchat

```


2. Соберите проект с помощью Makefile:
```bash
make

```


3. Запустите клиент:
```bash
./cchat

```



Для очистки скомпилированных файлов:

```bash
make clean

```

---

## 🔒 Безопасность и конфиденциальность

* Конфигурационные файлы хранятся по пути `~/.cchate/config.conf`. Права на директорию автоматически ограничиваются (`chmod 700`), исключая доступ для других пользователей системы.
* Программа не производит запись в системные лог-файлы и не использует сторонние трекеры.
